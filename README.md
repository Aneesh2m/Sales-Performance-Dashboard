# Sales-Performance-Dashboard

An Excel dashboard project analyzing retail sales, profit trends, product performance, and seasonal demand.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- Data Cleaning

## Key Insights
- Phones generated the highest sales
- Copiers had the highest profit margins
- Tables were loss-making despite strong sales
- Sales peaked during November and December
